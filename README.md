# 🍳 宿舍小食堂
### 材料不多，也能知道今天怎麼煮。

👉 [點我使用宿舍小食堂](https://lj3cole.github.io/dorm-kitchen/)

## 為什麼想做這個網頁？

住宿舍或租屋時，手邊的食材和設備通常不多。有時候只有雞胸肉、雞蛋或幾樣青菜，卻不知道可以怎麼煮；上網找食譜，又常常缺少其中的材料。

所以我想做「宿舍小食堂」，讓使用者輸入現有食材和設備，就能找到簡單的烹調方法，不需要先想好料理名稱。

## 可以做什麼？

- 輸入現有食材與調味料，尋找適合的烹調方法。
- 選擇「一起煮」或「分開煮」。
- 按照 1～6 人計算參考用量。
- 查看預估時間、備料方式、烹調步驟與熟度確認。
- 勾選已完成的步驟，方便邊看邊煮。
- 材料不足時，維持原本人數重新尋找其他方法。

## 怎麼使用？

1. 輸入食材，調味料可以留白。
2. 勾選手邊的設備。
3. 選擇用餐人數，以及一起煮或分開煮。
4. 按「找烹調方法」，再選擇想看的做法。
5. 依照步驟操作；材料不夠時，補填實際數量重新配對。

例如：輸入「雞胸肉」、勾選「電煮鍋」，即使沒有調味料，也能查看原味水煮的方法。

## 製作方式

這是我的 Vibe Coding 課程作品。我先和 AI 討論需求、整理規格書，再利用 AI 協助實作，最後使用 GitHub Pages 公開網站。

網頁使用 HTML、CSS 和 JavaScript，全部放在單一 index.html 中，手機和電腦都能使用。

## 目前的限制

目前依照內建的 19 項食材資料與搭配規則推薦做法，沒有串接 AI 即時生成食譜。未收錄的食材會提示未識別，不會隨意猜測做法。
